1. Product Loop

how it works
  1. 1
    Entry — 사용자가 SMS 또는 Telegram(@no_scroll_bot)으로 첫 메시지.
    전화번호 +1 (415) 305-4858 / +1 (415) 718-4828 모두 동일 백엔드로 라우팅.
  2. 2
    Account link — 봇이 noscroll.com/hi/<token>?platform=telegram 링크 발송 → X OAuth 연동
    X likes / bookmarks / follows 를 임포트해서 취향 시드 생성 (콜드스타트 X)
  3. 3
    Beat setting — 자연어로 "내가 뭘 보고 싶은지 / 뭘 빼야 하는지" 설정
    예: "crypto regulation news, but skip price-only posts"
  4. 4
    Sample → Trial → Paid — 무료 샘플 1회 → 7일 트라이얼 → $9.99/월
  5. 5
    Delivery — 사용자 지정 cadence (주 1 ~ 일 N회) + breaking 발생 시 즉시 인터럽트
  6. 6
    Reply loop — 모든 알림에 자연어 응답으로 dig-in / 조정 → 취향 강화

3. QR 로 Telegram 다이렉트 등록

deep-link · start_param

noscroll 이 쓰는 패턴은 Telegram 공식 start_param 딥링크. QR 은 그 URL 을 단순히 이미지로 인코딩한 것일 뿐 — 핵심은 1회용 토큰 ↔ chat_id 바인딩. 

# 흐름
[웹]                                [사용자]            [Telegram]
1. POST /api/telegram/link-token
   → token = uuid(), TTL 10분
   → Redis: token → web_user_id
                                    ─▶ QR 스캔
                                        https://t.me/kiko_fashion_ai_bot?start=<token>
2.                                        Telegram 앱 자동 오픈
3.                                        "Start" 버튼 노출
4.                                        탭 → 봇이 받는 메시지: "/start <token>"
5. webhook 수신
   chat_id ↔ token ↔ web_user_id 바인딩
   토큰 즉시 폐기
                                    ◀─ "환영해요! 계정 연결 완료 🐱"
A. 웹 → Telegram
  • kikoai/app 에서 토큰 발급 API
  • 프론트에서 qrcode npm 으로 QR 생성
  • 이 AI 서버 app/api/webhooks/telegram.py 에서 /start <token> 패턴 매칭
  • users.telegram_chat_id 업데이트 → 토큰 폐기
B. Telegram → 웹 (반대)
  • 봇이 https://kikoai.com/hi/<token> 발송
  • 웹에서 토큰 검증 → 세션 생성
  • Telegram-first 회원가입 플로우
  • noscroll 의 /hi/<token>?platform=telegram 이 정확히 이 패턴
결제 통합 (추후)
Telegram Stars / Payments 로 in-chat 구독 가능. noscroll 은 외부 결제 사용. $9.99/월 + 7일 트라이얼 모델은 PMF 검증 후 차용 권장.
